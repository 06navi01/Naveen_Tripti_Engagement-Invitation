## Music
The folder currently includes `assets/vaaroon-forever.mp3` because the user supplied that file. Playback is started by a user tap to comply with browser autoplay rules. A commercial/copyrighted song is not blocked merely because it is commercial, but you should have permission/licensing before publicly hosting it.

For a free replacement, use a track whose licence explicitly permits web use. Pixabay Music is one option; verify the individual track's licence before use. Replace `assets/vaaroon-forever.mp3` with your chosen MP3 and keep the same filename.

## Hosting
Upload the entire `engagement_invitation` folder to a static host such as Netlify. A public static site normally does not have a password by default. A custom domain is separate from hosting; the domain itself generally needs to be registered/owned. If you need a password-protected private invitation, choose a host/plan that provides access protection rather than relying on an unprotected public URL.

## Date/time
The invitation displays 11 November 2026. The calendar button uses 12:00–16:00 as a placeholder; change those times in `script.js` when the actual event time is known.
